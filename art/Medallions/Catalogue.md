# Medallion Catalogue

25 designs. Each is 3.0 mm thick: colour on both faces around a single-colour core (the first colour listed), printed in Bambu PLA Basic on the H2C. Print time and filament (including purge) are from slicing each project in Bambu Studio at 35 % infill.
